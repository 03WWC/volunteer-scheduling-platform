# 志愿者智能调度平台产品需求文档（PRD）

## 项目定位

面向音乐节、马拉松、展会、漫展、大型会议等活动场景的**智能化人力调度 SaaS 平台**。

**目标**：解决传统人工排班效率低、人员冲突、现场缺人无法快速调度、工资核算困难等问题。

**技术方向**：Spring Cloud Alibaba + AI智能算法 + Redis + MQ + Docker + Kubernetes

---

## 1. 项目背景

### 1.1 行业痛点

大型活动通常需要大量临时工作人员：

| 活动类型 | 典型岗位 |
|---------|---------|
| 音乐节 | 安保人员、引导人员、检票人员、后勤人员 |
| 马拉松 | 补给站志愿者、医疗协助人员、路线维护人员 |
| 漫展 | 入场管理、舞台区域管理、COS区域维护 |

**当前主要问题**：

| 问题 | 影响 |
|------|------|
| Excel 人工排班 | 效率低，容易出错 |
| 无法实时知道人员位置 | 现场调度困难 |
| 人员临时缺岗 | 响应慢 |
| 兼职人员时间冲突 | 投诉多 |
| 工资计算人工完成 | 财务压力大 |

**因此需要建设**：一个集活动管理、人员报名、智能排班、实时调度、结算管理于一体的平台。

## 4. 核心业务流程

### 4.1 活动创建流程

```
主办方
  ↓
创建活动
  ↓
设置活动地图
  ↓
划分区域
  ↓
创建岗位
  ↓
设置人数需求
  ↓
发布招募
```

**示例 — 音乐节**：

```
活动：2026 XX音乐节

区域：
  ├── A舞台区
  │   └── 岗位：安保（需求：20人）
  ├── B入口区
  │   └── 岗位：检票（需求：30人）
  └── C停车区
      └── 岗位：引导（需求：10人）
```

## 5. 功能需求

### 5.1 活动管理模块

**创建活动字段**：

| 字段 | 说明 |
|------|------|
| 活动名称 | 例如：2026 XX音乐节 |
| 开始时间 | — |
| 结束时间 | — |
| 地点 | — |
| 地图 | 上传活动地图 |
| 负责人 | — |

**支持操作**：修改活动 / 发布活动 / 关闭活动

### 5.2 区域岗位管理

**地图划区示例**：

```
+--------------+
|  舞台区 A    |
|              |
|--------------|
|  入口区 B    |
|              |
|--------------|
|  后台区 C    |
+--------------+
```

**岗位配置字段**：

| 字段 | 说明 |
|------|------|
| 岗位名称 | 如：安保、检票、引导 |
| 人数需求 | 如：20人 |
| 技能要求 | 如：有安保经验 |
| 工作时间 | 如：8:00-18:00 |
| 补贴标准 | 如：200元/天 |

### 5.3 人员报名系统

**志愿者信息**：

- 姓名
- 手机号
- 身份证认证
- 技能标签
- 可服务时间
- 历史评分

**支持操作**：报名 / 审核 / 淘汰 / 收藏

### 5.4 智能自动排班

**输入**：
- 岗位需求
- 人员列表
- 人员时间
- 技能
- 距离
- 历史评价

**输出示例**：

| 工作人员 | 时间段 | 区域 |
|---------|--------|------|
| 工作人员A | 8:00-12:00 | 入口区域 |
| 工作人员B | 12:00-18:00 | 舞台区域 |

### 5.5 冲突检测

**时间冲突检测**：

```
人员A
  ├── 8:00-12:00 → 入口
  └── 10:00-14:00 → 舞台  ❌ 冲突！
```

**地理冲突检测**：距离过远（10分钟内无法到达）→ 禁止排班

### 5.6 实时签到定位

**签到方式**：
- GPS 定位
- 二维码
- NFC

**后台地图展示**：

```
舞台区
  需求：20人
  实际：18人
  缺人：2人 ⚠️
```

### 5.7 AI 智能调度

**场景**：舞台区缺少 2 名安保

**系统计算维度**：
- 附近人员
- 空闲人员
- 技能匹配
- 距离

**推荐示例**：

```
张三 | 距离 80m | 空闲 | 评分 4.9 ⭐
→ 一键调度
```

### 5.8 工资/补贴结算

**自动计算公式**：

```
工资 = 基础工资 + 岗位补贴 + 加班费用 + 奖励
```

**支持**：
- 微信支付
- 银行转账
- 财务报表
