# 志愿者智能调度平台产品需求文档（PRD）

---

## 1. 产品背景

### 1.1 项目背景

大型活动通常需要大量临时工作人员：

| 活动类型 | 典型岗位 |
|----------|----------|
| 马拉松 | 起终点工作人员、补给站人员、医疗协助、道路维护 |
| 音乐节 | 安保、引导人员、VIP 服务、后勤保障 |
| 漫展 | 展区管理、秩序维护、Coser 服务 |

**目前主要问题**：

| 问题 | 描述 |
|------|------|
| 人员管理混乱 | Excel 报名，人工统计 |
| 排班效率低 | 靠负责人手工安排 |
| 冲突严重 | 同一人员重复安排 |
| 临时缺岗 | 无法快速补人 |
| 现场管理弱 | 不知道人员位置 |
| 结算困难 | 工时统计人工完成 |

**因此建设**：一个面向大型活动的智能化志愿者/安保调度平台。

## 2. 产品目标

### 2.1 核心目标

```
活动创建
    ↓
区域岗位配置
    ↓
人员报名
    ↓
AI 智能排班
    ↓
自动检测冲突
    ↓
发布排班
    ↓
现场签到定位
    ↓
实时调度
    ↓
自动结算
```

### 4.4 智能排班系统（核心）

**排班目标**：

```
人员 + 时间 + 区域 + 岗位 = 最佳方案
```

**排班规则**：

| 规则 | 说明 |
|------|------|
| 规则 1：时间冲突 | 禁止同一人员同时段出现在不同区域 |
| 规则 2：距离优化 | 缺人时寻找距离最近 + 当前空闲 + 技能匹配 |
| 规则 3：公平原则 | 避免有人工作 20 小时、有人只工作 1 小时 |

**AI 智能排班**：

| 输入 | 输出 |
|------|------|
| 岗位需求、人员技能、时间、位置、历史评价 | 最佳排班方案 |

### 4.5 排班发布

- 一键生成排班表
- 微信通知 / APP 通知 / 短信通知

**排班表示例**：

| 姓名 | 区域 | 岗位 | 时间 |
|------|------|------|------|
| 张三 | 入口 | 安保 | 18:00-23:00 |

### 4.6 活动现场管理

**签到方式**：

- 二维码签到：扫码 → 上传 GPS → 记录时间

**状态**：

| 状态 | 说明 |
|------|------|
| 未签到 | 尚未到场 |
| 已签到 | 正常在岗 |
| 迟到 | 超时签到 |
| 离岗 | 提前离开 |

### 4.7 实时定位

地图实时显示各区域人员分布：
- A 区域：● 张三　● 李四
- B 区域：● 王五

### 4.8 紧急调度

**场景**：C 区突然缺 5 人

**系统响应**：
1. 查询附近人员
2. 筛选空闲人员
3. 技能匹配
4. 推荐：王五 | 距离 100 米 | 空闲 → 一键调度

### 4.9 工资/补贴结算

**计算公式**：

```
收入 = 基础补贴 + 加班费用 + 奖励
```

**生成**：结算单 → 支付记录
