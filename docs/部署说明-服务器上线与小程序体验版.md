# 服务器上线与小程序体验版说明

本文档用于把项目部署到云服务器，并把微信小程序作为体验版发给朋友测试。

## 1. 上线目标

- 后台网页：浏览器访问 `https://your-domain.com`
- 后端接口：统一走 `https://your-domain.com/api`
- 小程序体验版：请求域名配置为 `https://your-domain.com`

如果暂时没有域名，也可以先用 `http://服务器IP` 测后台网页；但小程序体验版给朋友使用时，建议必须准备 HTTPS 域名并在微信公众平台配置合法请求域名。

## 2. 服务器准备

服务器需要安装：

- Docker
- Docker Compose
- JDK 17
- Maven 3.6+
- Node.js 18+

安全组建议只对公网开放：

- `80`
- `443`

MySQL、Redis、RabbitMQ、Nacos 在 `docker-compose.prod.yml` 中默认只绑定 `127.0.0.1`，不要直接暴露到公网。

## 3. 准备生产环境变量

复制环境变量模板：

```bash
cp deploy/prod.env.example deploy/prod.env
```

然后修改：

```bash
MYSQL_ROOT_PASSWORD=你的MySQL密码
REDIS_PASSWORD=你的Redis密码
RABBITMQ_DEFAULT_PASS=你的RabbitMQ密码
WECHAT_APP_ID=你的小程序AppID
WECHAT_APP_SECRET=你的小程序AppSecret
```

## 4. 修改域名

把以下文件中的 `your-domain.com` 替换成你的真实域名：

- `miniapp/.env.production`
- `deploy/nginx/conf.d/volunteer-platform.conf`

后台前端生产环境默认请求 `/api`，不需要额外改接口地址。

## 5. 打包后端

在项目根目录执行：

```bash
mvn -DskipTests package
```

如果服务器 Maven 默认不是 JDK 17，先设置：

```bash
export JAVA_HOME=/path/to/jdk17
export PATH=$JAVA_HOME/bin:$PATH
```

## 6. 打包后台网页

```bash
cd frontend-admin
npm install
npm run build
cd ..
```

产物会生成到：

```text
frontend-admin/dist
```

## 7. 启动服务器服务

```bash
docker compose -f docker-compose.prod.yml --env-file deploy/prod.env up -d --build
```

查看服务状态：

```bash
docker compose -f docker-compose.prod.yml ps
```

查看日志：

```bash
docker compose -f docker-compose.prod.yml logs -f gateway
docker compose -f docker-compose.prod.yml logs -f user-service
```

## 8. 配置 HTTPS

申请证书后，把证书放到：

```text
deploy/nginx/certs/fullchain.pem
deploy/nginx/certs/privkey.pem
```

然后编辑：

```text
deploy/nginx/conf.d/volunteer-platform.conf
```

把 HTTPS server block 取消注释，并替换 `server_name your-domain.com`。

重启 Nginx：

```bash
docker compose -f docker-compose.prod.yml restart nginx
```

## 9. 微信公众平台配置

进入微信公众平台：

```text
开发管理 -> 开发设置 -> 服务器域名
```

配置 request 合法域名：

```text
https://your-domain.com
```

注意：这里只填域名，不填 `/api` 路径。小程序代码里的接口地址仍然可以是 `https://your-domain.com/api`。

## 10. 上传小程序体验版

修改：

```text
miniapp/.env.production
```

确保：

```text
VITE_API_BASE_URL=https://your-domain.com/api
```

打包微信小程序：

```bash
cd miniapp
npm install
npm run build:mp-weixin
```

微信开发者工具导入：

```text
miniapp/dist/build/mp-weixin
```

然后点击：

```text
上传 -> 微信公众平台 -> 版本管理 -> 设为体验版
```

把朋友添加为体验成员后，对方扫码即可体验。

## 11. 简单验收路线

1. 浏览器打开 `https://your-domain.com`
2. 后台登录
3. 创建活动、区域、岗位
4. 发布排班
5. 进入签到记录，生成岗位通用二维码
6. 小程序体验版登录并扫码
7. 后台刷新签到记录，确认出现签到数据

## 12. 常见问题

- 小程序请求失败：检查微信公众平台合法请求域名是否配置 HTTPS 域名。
- 后台能打开但接口失败：检查 Nginx `/api/` 是否代理到 `gateway:8080`。
- 服务互相调用失败：检查 Nacos 容器是否健康，业务服务是否注册成功。
- 签到失败：确认当前小程序用户已经在该岗位排班，岗位通用码只允许已排班志愿者签到。
