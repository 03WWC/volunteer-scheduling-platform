# 阿里巴巴 Java 开发规范 — 代码格式

> 来源：《阿里巴巴Java开发手册》| 全部为【强制】级别

---

## 核心规则

| # | 规则 | 说明 |
|---|------|------|
| 1 | 缩进用 **4 个空格**，不用 Tab | IDE 统一设置 |
| 2 | 行宽不超过 **120 字符** | 超长行适当换行 |
| 3 | `if`/`for`/`while`/`switch`/`do` 与括号之间**必须加空格** | `if (condition)` 而非 `if(condition)` |
| 4 | 运算符左右各加**一个空格** | `a = b + c` 而非 `a=b+c` |
| 5 | 大括号规则 | 左大括号前不换行，左大括号后换行 |

---

## 格式示例

### if/for/while 格式

```java
// 正例
if (user != null) {
    doSomething();
}

for (int i = 0; i < count; i++) {
    process(i);
}

while (iterator.hasNext()) {
    handle(iterator.next());
}

// 反例
if(user!=null){           // ❌ 缺少空格，大括号位置错误
    doSomething();}
```

### 运算符空格

```java
// 正例
int result = a + b * c;
String name = firstName + " " + lastName;

// 反例
int result=a+b*c;         // ❌ 无空格
```

### 大括号风格（K&R）

```java
// 正例 — 左大括号不换行
public class UserService {
    public void process() {
        if (condition) {
            // ...
        }
    }
}

// 反例 — 左大括号换行（Allman 风格）
public class UserService
{                          // ❌
    public void process()
    {                      // ❌
    }
}
```

## IDE 统一配置建议

在项目 `.editorconfig` 中统一设定：

```ini
[*.java]
indent_style = space
indent_size = 4
max_line_length = 120
```
