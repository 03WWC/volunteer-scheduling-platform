## 2. 微服务拆分

### 2.1 活动服务 activity-service

**职责**：活动创建、区域管理、岗位管理

**技术栈**：SpringBoot + MyBatis + MySQL

**核心表结构**：

**activity（活动表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| name | varchar | 活动名称 |
| start_time | datetime | 开始时间 |
| end_time | datetime | 结束时间 |
| location | varchar | 地点 |

**area（区域表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| activity_id | bigint | 活动 ID |
| gps | text | GPS 范围 |

**position（岗位表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| area_id | bigint | 区域 ID |
| need_count | int | 需求人数 |
| salary | decimal | 补贴金额 |

### 2.2 排班服务 schedule-service（核心）

**职责**：自动排班、冲突检测、排班发布

**接口**：

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/schedule/create` | 创建排班 |
| GET | `/schedule/list` | 排班列表 |

**算法流程**：

```
获取岗位需求
    ↓
过滤时间冲突人员
    ↓
技能匹配
    ↓
距离排序
    ↓
AI 优化
    ↓
生成方案
```

**Redis 设计**：

| Key | 用途 |
|-----|------|
| `volunteer:free:{date}` | 人员空闲缓存（value: [10001, 10002, ...]） |

---

### 2.3 调度服务 dispatch-service

**职责**：实时调度（GPS 计算）

**流程**：

```
缺岗事件
    ↓
MQ 通知
    ↓
查询附近人员（Redis GEO）
    ↓
推荐人员
    ↓
完成调度
```

**Redis GEO 使用**：

```bash
GEOADD volunteer_location <lng> <lat> <userId>
GEORADIUS volunteer_location <lng> <lat> 500 m
```

### 2.4 结算服务 settlement-service

**职责**：工资计算

**流程**：

```
签到记录 → 工作时长 → 规则计算 → 生成账单 → 支付
```

## 6. 服务间通信 — Feign 设计（核心）

### 6.1 通信原则

| 场景 | 方式 | 说明 |
|------|------|------|
| 同步查询 / 同步写 | **OpenFeign** | 实时返回结果 |
| 异步通知 / 削峰 | **RabbitMQ** | 解耦、削峰、最终一致 |
| 实时位置 / 在线状态 | **Redis** | 高频读写，不走 RPC |

### 6.2 Feign Client 模块规范

每个被调用的服务提供独立的 `-client` 模块（JAR），包含 Feign 接口 + DTO：

```
├── activity-service
│   └── activity-service-client    # Feign 接口 + PositionDTO 等
├── schedule-service
│   └── schedule-service-client
├── settlement-service
│   └── settlement-service-client
```

**调用方**只需引入被调用方的 `-client` 依赖即可。

### 6.3 服务调用关系矩阵

```
                    ┌─────────────┐
                    │   Gateway   │
                    └──────┬──────┘
                           │
        ┌──────────────────┼──────────────────────┐
        │                  │                      │
        ▼                  ▼                      ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────────┐
│activity-     │  │schedule-     │  │dispatch-         │
│service       │◄─┤service       │  │service           │
│              │  │              │  │                  │
└──────┬───────┘  └──────┬───────┘  └────────┬─────────┘
       │                 │                   │
       │     Feign       │     Feign         │
       ▼                 ▼                   ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────────┐
│user-service  │  │location-     │  │settlement-       │
│              │  │service       │  │service           │
└──────────────┘  └──────────────┘  └──────────────────┘
```

| 调用方 | 被调用方 | 场景 | Feign Client |
|--------|----------|------|-------------|
| schedule-service | activity-service | 获取岗位/区域数据 | `ActivityClient` |
| schedule-service | user-service | 获取志愿者技能/时间 | `UserClient` |
| dispatch-service | location-service | 查询附近人员（GPS） | `LocationClient` |
| dispatch-service | schedule-service | 查询当前排班 | `ScheduleClient` |
| settlement-service | schedule-service | 获取签到/工时记录 | `ScheduleClient` |
| settlement-service | activity-service | 获取岗位补贴标准 | `ActivityClient` |

### 6.4 Feign 统一配置

```java
// common-core 中定义全局 Feign 配置
@Configuration
public class FeignConfig {

    // 1. 超时配置
    @Bean
    public Request.Options options() {
        return new Request.Options(
            Duration.ofSeconds(3),   // connectTimeout
            Duration.ofSeconds(10),  // readTimeout
            true                     // followRedirects
        );
    }

    // 2. 重试配置（非幂等写操作不重试）
    @Bean
    public Retryer retryer() {
        return new Retryer.Default(100, 1000, 2); // 最多重试 2 次
    }

    // 3. 日志级别（开发期 FULL，生产 HEADERS）
    @Bean
    public Logger.Level feignLoggerLevel() {
        return Logger.Level.BASIC;
    }
}
```

### 6.5 JWT Token 透传（RequestInterceptor）

```java
// Feign 调用时自动携带当前请求的 JWT Token
@Component
public class FeignAuthInterceptor implements RequestInterceptor {

    @Override
    public void apply(RequestTemplate template) {
        ServletRequestAttributes attributes =
            (ServletRequestAttributes) RequestContextHolder.getRequestAttributes();
        if (attributes != null) {
            String token = attributes.getRequest().getHeader("Authorization");
            if (StringUtils.hasText(token)) {
                template.header("Authorization", token);
            }
        }
    }
}
```

### 6.6 Sentinel 熔断降级

```yaml
# 每个 Feign Client 开启 Sentinel
feign:
  sentinel:
    enabled: true
  client:
    config:
      default:
        connectTimeout: 3000
        readTimeout: 10000
```

**降级策略**：

| 策略 | 触发条件 | 行为 |
|------|----------|------|
| 慢调用比例 | 响应时间 > 1s 的比例 > 50% | 熔断 30s |
| 异常比例 | 异常比例 > 50% | 熔断 30s |
| 异常数 | 1 分钟内 > 20 个异常 | 熔断 30s |

**FallbackFactory 示例**：

```java
@FeignClient(
    name = "activity-service",
    fallbackFactory = ActivityClientFallbackFactory.class
)
public interface ActivityClient {

    @GetMapping("/position/list")
    Result<List<PositionDTO>> getPositionList(@RequestParam("activityId") Long activityId);
}

@Component
public class ActivityClientFallbackFactory implements FallbackFactory<ActivityClient> {

    @Override
    public ActivityClient create(Throwable cause) {
        log.error("activity-service 调用失败", cause);
        return activityId -> Result.fail("活动服务暂不可用，请稍后重试");
    }
}
```

### 6.7 Feign 完整调用示例

```java
// === 调用方：schedule-service ===

// 1. 引入依赖
// pom.xml: 依赖 activity-service-client

// 2. 注入 Client
@Service
public class ScheduleServiceImpl implements ScheduleService {

    @Autowired
    private ActivityClient activityClient;

    @Override
    public ScheduleVO createSchedule(Long activityId, ScheduleDTO dto) {
        // 通过 Feign 获取岗位列表
        Result<List<PositionDTO>> result = activityClient.getPositionList(activityId);
        if (!result.isSuccess()) {
            throw new BusinessException("获取岗位信息失败");
        }
        List<PositionDTO> positions = result.getData();
        // ... 排班逻辑
    }
}
```

### 6.8 Feign vs MQ 选择决策树

```
需要立即返回结果？
├── 是 → OpenFeign（同步调用）
└── 否 → 需要削峰 / 广播 / 重试？
          ├── 是 → RabbitMQ（异步消息）
          └── 否 → OpenFeign + 异步线程池
```

## 10. 阿里开发规范

遵循《阿里巴巴 Java 开发手册》：

| 规范 | 说明 |
|------|------|
| RESTful API | 资源导向 URL 设计 |
| DTO 隔离 | 分层数据传输对象 |
| Controller 不写业务 | 只做参数校验和转发 |
| Service 事务控制 | `@Transactional` 管理 |
| VO 统一返回 | `{"code":200, "message":"success", "data":{}}` |

**统一返回格式**：

```json
{
    "code": 200,
    "message": "success",
    "data": {}
}
```
