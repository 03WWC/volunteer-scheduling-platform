## 二、阿里标准分层架构

| 层级 | 名称 | 职责说明 |
|------|------|----------|
| 开放接口层 | Open API | 封装 Service 接口暴露为 RPC 接口；通过 Web 封装为 HTTP 接口；网关安全控制、流量控制 |
| 终端显示层 | View | 各端模板渲染并执行显示（Velocity/JS/JSP/移动端） |
| Web 层 | Controller | 访问控制转发、基本参数校验、不复用的业务简单处理 |
| Service 层 | Service | 相对具体的业务逻辑服务层 |
| Manager 层 | Manager | 通用业务处理层：对第三方平台封装、对 Service 层通用能力下沉（缓存/中间件）、与 DAO 层交互对多个 DAO 组合复用 |
| DAO 层 | Mapper | 数据访问层，与底层 MySQL/Oracle/HBase 等进行数据交互 |
| 外部接口层 | External | 其它部门 RPC 服务、第三方 HTTP 接口（淘宝开放平台、支付宝、高德地图等） |

## 三、各层领域模型命名规约【强制】

| 对象 | 全称 | 用途 |
|------|------|------|
| DO | Data Object | 与数据库表结构一一对应，通过 DAO 层向上传输 |
| DTO | Data Transfer Object | 数据传输对象，Service 或 Manager 向外传输 |
| BO | Business Object | 业务对象，由 Service 层输出的封装业务逻辑的对象 |
| VO | View Object | 显示层对象，通常是 Web 向模板渲染引擎层传输的对象 |
| Query | 数据查询对象 | 各层接收上层的查询请求，超过 2 个参数封装使用，禁止用 Map 传参 |

**【强制】** POJO 是 DO/DTO/BO/VO 的统称，禁止命名成 xxxPOJO。

## 四、项目目录结构（阿里风格）

```
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── com/
│   │   │       └── {company}/
│   │   │           └── {project}/
│   │   │               ├── Application.java                    # 启动类
│   │   │               ├── common/                             # 公共模块
│   │   │               │   ├── annotation/                     # 自定义注解
│   │   │               │   ├── config/                         # 配置类
│   │   │               │   ├── constant/                       # 常量类（按功能分类）
│   │   │               │   │   ├── CacheConsts.java
│   │   │               │   │   └── ConfigConsts.java
│   │   │               │   ├── enums/                          # 枚举类（Enum 后缀）
│   │   │               │   ├── exception/                      # 异常处理
│   │   │               │   │   ├── BusinessException.java
│   │   │               │   │   └── GlobalExceptionHandler.java
│   │   │               │   ├── interceptor/                    # 拦截器
│   │   │               │   └── util/                           # 工具类
│   │   │               ├── modules/                            # 业务模块
│   │   │               │   └── {module}/                       # 模块名
│   │   │               │       ├── controller/                 # Web 层（对外接口）
│   │   │               │       │   └── UserController.java
│   │   │               │       ├── service/                    # Service 层
│   │   │               │       │   ├── UserService.java
│   │   │               │       │   └── impl/
│   │   │               │       │       └── UserServiceImpl.java  # Impl 后缀
│   │   │               │       ├── manager/                    # Manager 层（可选）
│   │   │               │       │   └── UserCacheManager.java
│   │   │               │       ├── dao/                        # DAO 层
│   │   │               │       │   └── UserDAO.java
│   │   │               │       ├── entity/                     # 数据对象（DO）
│   │   │               │       │   └── UserDO.java
│   │   │               │       ├── dto/                        # 数据传输对象
│   │   │               │       │   └── UserDTO.java
│   │   │               │       └── vo/                         # 视图对象
│   │   │               │           └── UserVO.java
│   │   │               └── config/                             # 模块独立配置
│   │   └── resources/
│   │       ├── application.yml                                 # 主配置
│   │       ├── application-dev.yml                             # 开发环境
│   │       ├── application-prod.yml                            # 生产环境
│   │       ├── mapper/                                         # MyBatis XML
│   │       │   └── {module}/
│   │       │       └── UserDAO.xml
│   │       ├── static/                                         # 静态资源
│   │       └── template/                                       # 页面模板
│   └── test/                                                   # 单元测试（*Test）
├── pom.xml
└── README.md
```
