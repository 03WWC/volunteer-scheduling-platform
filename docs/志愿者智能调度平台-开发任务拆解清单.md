# 志愿者智能调度平台 — 开发任务拆解清单

---

## 一、基础工程

### 任务 1：项目初始化

| 项 | 内容 |
|----|------|
| 负责人 | 后端 |
| 内容 | Spring Cloud Alibaba 搭建、Nacos 注册中心、Gateway 搭建、**Feign/Sentinel 通用配置**、Docker 环境 |
| 周期 | 3 天 |
| 产出 | 基础微服务框架（含 common-core Feign 配置、Gateway 鉴权路由、Docker 开发环境） |

#### 1.1 根工程

- 创建 Maven 多模块父 POM
- 统一依赖版本管理（Spring Boot 3.3.x + Spring Cloud 2023.0.x + Alibaba 2023.0.1.x）
- Maven Wrapper（mvnw）

#### 1.2 common-core 公共模块

- 统一返回体 `Result<T>`（code + message + data）
- 公共异常类 `BusinessException`
- 全局异常处理器 `GlobalExceptionHandler`
- **Feign 统一配置**：超时 3s/10s、重试 2 次、日志级别
- **Feign JWT Token 透传**：`FeignAuthInterceptor`（RequestInterceptor）
- **Sentinel 熔断配置**：`feign.sentinel.enabled=true`
- 统一常量类（按功能分类）

#### 1.3 gateway 网关模块

- Spring Cloud Gateway 路由配置
- Nacos 服务发现
- JWT Token 校验过滤器
- 全局 CORS 配置
- 限流配置（Sentinel）

#### 1.4 Docker 开发环境

- `docker-compose.yml`：Nacos + MySQL + Redis + RabbitMQ
- 各服务 Dockerfile 模板

## 二、活动服务开发

### 模块结构

```
activity-service/
├── activity-service-client/     # Feign 接口 + DTO（供其他服务引入）
│   ├── api/ActivityClient.java
│   ├── dto/ActivityDTO.java
│   ├── dto/AreaDTO.java
│   └── dto/PositionDTO.java
└── activity-service-server/     # 服务实现
    └── src/main/java/com/volunteer/platform/activity/
        ├── ActivityServiceApplication.java
        ├── controller/          # Web 层：参数校验、接口转发
        ├── service/             # Service 接口：业务编排
        │   └── impl/            # Service 实现类，统一 Impl 后缀
        ├── manager/             # 通用业务能力：缓存、中间件、组合 DAO
        ├── dao/                 # MyBatis Mapper/DAO
        ├── entity/              # DO：与数据库表一一对应
        ├── dto/                 # DTO：服务间/层间传输对象
        ├── vo/                  # VO：接口响应展示对象
        └── query/               # Query：查询条件对象，禁止 Map 传参
```

### Feign Client 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/position/list` | 获取岗位列表（供排班服务调用） |
| `GET` | `/position/{id}` | 获取单个岗位详情 |
| `GET` | `/area/list` | 获取区域列表（供调度服务调用） |

### 活动管理

| 接口 | 说明 |
|------|------|
| `POST /activity/create` | 创建活动 |
| `GET /activity/page` | 分页查询活动列表 |
| `PUT /activity/update` | 修改活动 |
| `DELETE /activity/{id}` | 删除活动 |

### 区域管理

- 地图区域保存
- GPS 范围管理
- 区域负责人

### 岗位管理

- 岗位 CRUD
- 人数需求配置
- 补贴配置

```
├── schedule-service-client/     # Feign 接口 + DTO

        ├── service/

        ├── dao/
        ├── entity/
        ├── dto/
        ├── vo/
        └── query/
```

### Feign Client 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/schedule/{activityId}/detail` | 获取排班详情（供调度/结算服务调用） |
| `GET` | `/schedule/{id}/checkin-records` | 获取签到记录（供结算服务调用） |

### 依赖的 Feign 调用（本服务作为调用方）

```java
@FeignClient(name = "activity-service")   // → 获取岗位/区域数据
@FeignClient(name = "user-service")       // → 获取志愿者技能/时间
```

### 排班算法

| 子任务 | 说明 |
|--------|------|
| 时间匹配 | 匹配志愿者空闲时间与岗位需求 |
| 冲突检测 | 检测时间冲突、地理冲突 |
| 人员筛选 | 按技能、距离、评分排序 |
| 自动生成排班 | 调用 AI 模块输出最优方案 |

### Redis 优化

| 子任务 | 说明 |
|--------|------|
| 空闲人员缓存 | `volunteer:free:{date}` |
| 排班锁 | `lock:schedule:{activityId}` 防重复 |

### 排班发布

- 排班确认
- MQ 通知
- 消息推送（微信/APP/短信）
